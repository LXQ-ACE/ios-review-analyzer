# iOS App评论分析工具 - 需求规格说明书
## 1.项目概述
### 1.1 项目背景
App Store海量的用户评论蕴藏大量产品痛点、功能诉求、用户满意度信息。人工逐条阅读整理评论效率低下，本工具基于Python+Streamlit搭建可视化Web应用，自动抓取、清洗、AI解析iOS应用商店评论，自动输出产品需求文档与测试用例，帮助产品研发人员快速从用户反馈挖掘迭代方向。
### 1.2 项目目标
1. 支持在线抓取App Store应用评论，同时兼容本地CSV评论文件导入
2. 完成原始评论数据清洗、格式标准化
3. 使用大模型完成评论语义分类、问题优先级判定、证据等级评估
4. 根据分析结果自动生成PRD需求条目、配套测试用例
5. 提供美观的可视化操作界面，支持日间/夜间模式，操作简单、响应流畅
### 1.3 适用范围
本系统面向产品经理、开发人员、测试人员，用于iOS移动端应用的用户反馈分析，不支持安卓应用商店数据源。
## 2.功能性需求
### 2.1 数据输入模块
|编号|功能名称|功能描述|
| ---- | ---- | ---- |
|F‑001|在线抓取评论|输入App Store链接，程序自动爬取公开用户评论，导出原始CSV文件|
|F‑002|本地文件导入|支持上传CSV格式评论数据集，自动识别通用字段，完成格式兼容|
|F‑003|内置示例数据集|自带一份标准英文评论样例，无需准备数据即可一键体验全部分析流程|
### 2.2 数据清洗模块
|编号|功能名称|功能描述|
| ---- | ---- | ---- |
|F‑004|空值过滤|自动剔除评论内容为空、评分缺失的无效数据|
|F‑005|字段标准化|自动适配多种CSV列名，统一转换为程序内部标准字段|
|F‑006|异常数据容错|开启CSV容错解析，处理评论文本内部含有逗号等特殊字符造成的解析失败问题|
### 2.3 AI智能分析模块
|编号|功能名称|功能描述|
| ---- | ---- | ---- |
|F‑007|语义自动分类|AI将评论分为Bug反馈、功能建议、体验吐槽、好评夸赞4大类|
|F‑008|优先级判定|根据反馈频次、严重程度划分高、中、低三个优化优先级|
|F‑009|证据等级评估|判断反馈信息的可靠程度，区分个案问题与普遍性问题|
|F‑010|矛盾反馈识别|识别出存在冲突、意见两极分化的用户评价|
### 2.4 结果生成与导出模块
|编号|功能名称|功能描述|
| ---- | ---- | ---- |
|F‑011|自动生成PRD条目|从用户反馈提炼规范化产品需求，包含需求描述、优先级、目标用户|
|F‑012|自动生成测试用例|针对每一条需求，生成可直接使用的测试步骤、预期结果|
|F‑013|分析报告导出|支持导出分析结果、PRD文档、测试用例为CSV文件，本地保存|
## 3.非功能性需求
### 3.1 UI&交互需求
1. 整体主题色调：紫色为主色调，配色柔和协调
2. 支持日间、夜间两种显示模式一键切换
3. 页面布局清晰，模块分区明确，具备基础响应式适配
4. 操作按钮、提示文字对比度充足，夜间模式无文字看不清等显示bug
### 3.2 性能需求
1. 百条以内评论数据集，整体全流程分析时长控制在60秒以内
2. 文件导入、数据解析具备异常捕获，输入错误文件友好提示，程序不直接崩溃
### 3.3 可拓展性需求
1. 项目代码模块化拆分，抓取、清洗、AI分析、UI界面相互解耦
2. 配置项统一存放，大模型密钥、基础参数可以直接在配置文件修改
## 4.约束条件
1. 网络抓取仅用于App Store公开可访问的评论数据
2. AI分析功能需要配置合法可用的大模型API Key才可正常运行
3. 文件仅支持UTF‑8编码CSV格式导入
