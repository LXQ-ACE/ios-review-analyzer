# iOS App评论分析工具‑接口&数据字典说明书
## 1.外部API接口
### 1.1 App Store评论抓取接口
- 请求地址：Apple公开RSS评论接口
- 请求方式：GET
- 入参：appId 目标iOS应用编号
- 请求头：模拟浏览器User‑Agent，防止接口拒绝访问
- 返回数据格式：JSON
- 返回字段说明
|字段|含义|
| ---- | ---- |
|id|评论唯一标识|
|author|评论作者昵称|
|im:rating|用户评分(1‑5)|
|title|评论标题|
|content|评论正文|
|version|应用版本号|

### 1.2 大模型LLM分析接口
本项目使用OpenAI兼容格式接口
- 请求方式：POST
- 请求头：Authorization存放API密钥
- 请求体：包含系统提示词、待分析评论文本、输出格式约束
- 返回：JSON结构化分析结果
## 2.内部数据字典
### 2.1 原始评论数据表 review_data
|字段名|字段类型|字段说明|
| ---- | ---- | ---- |
|review_id|字符串|评论唯一编号|
|rating|整数|用户评分1~5分|
|title|字符串|评论标题|
|content|字符串|评论详细正文|
|author|字符串|评论作者名称|
|version|字符串|对应的App版本号|

### 2.2 AI分析结果表 ai_result
|字段名|字段类型|字段说明|
| ---- | ---- | ---- |
|review_id|字符串|关联原始评论ID|
|category|字符串|评论分类：Bug反馈 /功能建议 /体验吐槽 /好评夸赞|
|priority|字符串|优先级：高 /中 /低|
|evidence_level|字符串|证据等级：个案反馈 /少量用户 /普遍问题|
|summary|字符串|AI提炼简短反馈摘要|

### 2.3 PRD需求数据表 prd_output
|字段名|字段类型|字段说明|
| ---- | ---- | ---- |
|demand_id|字符串|需求编号|
|demand_name|字符串|需求名称|
|demand_desc|字符串|详细需求描述，来源于用户评论|
|priority|字符串|需求优先级|
|origin_comment_ids|字符串|来源对应的评论id列表，实现需求‑评论溯源|

### 2.4 测试用例数据表 testcase_output
|字段名|字段类型|字段说明|
| ---- | ---- | ---- |
|case_id|字符串|用例编号|
|demand_id|字符串|关联PRD需求编号|
|precondition|字符串|测试前置条件|
|step|字符串|详细操作步骤|
|expect_result|字符串|预期结果|
## 3.导入导出CSV字段规范
### 输入CSV最少需要包含字段：
评分、评论标题、评论正文
程序可自动兼容字段命名差异，自动映射。
### 导出文件：
1. cleaned_reviews.csv 清洗之后的评论
2. ai_analysis_result.csv AI解析完整结果
3. prd_list.csv 自动生成的产品需求
4. test_cases.csv 自动生成的测试用例
